# 使用 GPT Image 2 + Seedance 2.0 制作任意长度 AI 影片

> 来源：[Create Seamless AI Films of ANY Length (GPT Image 2 + Seedance 2.0)](https://www.youtube.com/watch?v=KxRR8uiex_s)
> 频道：Tao Prompts | 发布日期：2026-05-01 | 播放量：40K+
> 平台：Higgsfield AI (higgsfield.ai)

---

## 核心思路

将长视频拆解为 **分镜脚本 → 分段动画 → 无缝拼接** 三步流程，利用 GPT Image 2 的推理 + 文字能力生成分镜，再用 Seedance 2.0 视频模型逐段动画化，最终合成任意长度的 AI 影片。

---

## 完整流程

### 第一步：用 GPT Image 2 生成分镜脚本 (Storyboard)

**目的**：用 AI 一次性生成包含多个镜头的完整故事分镜板。

**操作步骤**：

1. 在 Higgsfield AI 中选择 **GPT Image 2** 模型
2. 上传角色参考图（如主角照片）
3. 编写简短的故事描述 prompt（一句话即可）
4. 设置参数：
   - 画质：推荐高质量
   - 分辨率：按需
   - 宽高比：**16:9**（推荐）
5. 生成分镜板

**输出结果**：一张包含 12 个画格的分镜板图片，每个画格下方附带文字描述（后续作为视频 prompt 使用）。

**注意事项**：
- 检查是否有重复画面（如 panel 3 和 panel 11 内容相同）
- 如有重复，将分镜板作为参考图上传，prompt 指定修改对应 panel
  - 例：「Adjust shot 11 so it's not a repeat of shot number three」

---

### 第二步：创建角色参考表 (Character Reference Sheet)

**目的**：确保在多段视频生成中角色外观保持一致。

**为什么需要**：如果不提供角色参考表，AI 视频生成器会在不同片段中产生角色外观差异（例如机器人腿部比例失调等）。

**操作步骤**：

1. 使用 GPT Image 2 模型
2. 上传角色的原始图片
3. Prompt 要求生成 character reference sheet（多角度参考图）
4. 生成后保存，作为后续视频生成的参考

---

### 第三步：用 Seedance 2.0 逐段生成视频

**核心限制**：Seedance 2.0 单次最长生成 **15 秒** 视频。

**解决方案**：将 12 格分镜板按行裁剪（每行 4 格），每行生成一个 15 秒视频。

**操作步骤**：

1. **裁剪分镜板**：将 12 格分镜按行裁剪为 3 组（每组 4 格）
   - 技术细节：裁剪后需将该行图像放置在一张 16:9 画布上，确保 Higgsfield 能正确识别
2. **上传素材**：
   - 裁剪后的分镜行图片
   - 角色参考表
3. **编写 Prompt**：
   ```
   Generate a scene using the shots in the uploaded film storyboard @[分镜图片引用].
   
   Shot 1 (0-4s): [从分镜板复制文字描述]
   Shot 2 (4-8s): [从分镜板复制文字描述]
   Shot 3 (8-12s): [从分镜板复制文字描述]
   Shot 4 (12-15s): [从分镜板复制文字描述]
   
   The robot @[角色参考表引用] should match the reference sheet.
   
   No music. No subtitles.
   ```
4. **关键技巧**：
   - 使用 `@` 标记引用不同的上传图片
   - 为每个 shot 分配时间段
   - 在多处引用角色参考表（在提到角色的地方都加标记）
   - 末尾加 `No music. No subtitles.`（方便后期合成）
   - 设置视频时长为最大值 15 秒
5. **重复以上步骤**生成第 2 行、第 3 行的视频

**输出**：3 个 15 秒视频片段 → 组合为约 45 秒连续影片

---

### 第四步：扩展分镜以延长影片

**目的**：将故事无限延伸，生成更多分镜和视频。

**操作步骤**：

1. 将已有的 12 格分镜板上传为参考
2. 同时上传所有角色参考表
3. Prompt 示例：
   ```
   Generate the next page of the storyboard from image 1, which continues the story
   with 12 panels using the uploaded images. [新的剧情方向描述]
   ```
4. 获得新的 12 格分镜后，重复第三步流程

**数学计算**：2 页分镜 × 3 段视频/页 × 15 秒/段 = 90 秒视频

---

### 第五步：创建无缝过渡 (Seamless Transitions)

**问题**：当动态场景（如打斗）跨越多个 15 秒片段时，片段之间的过渡不自然。

**解决方案**：使用上一段视频的 **最后一帧** 作为下一段视频的 **起始帧**。

**操作步骤**：

1. 使用 **视频帧提取工具 (Video Frame Extractor)** 保存上一段视频的最后一帧
2. 生成下一段视频时，在上传素材中加入这一帧截图
3. 修改 Prompt，加入起始帧指令：
   ```
   Generate a scene using the uploaded film storyboard fight sequence,
   starting with this image frame @[最后一帧截图] of [描述帧内容].
   
   Shot 1 (0-4s): [描述]
   Shot 2 (4-8s): [描述]
   ...
   ```
4. 这样 AI 会从该帧开始生成后续内容，实现自然过渡

## 注意事项 & Tips

1. **图片审核**：Higgsfield 会检查上传图片的合规性（版权）。原创角色偶尔也会被误判为不合规，多试几次即可通过。
2. **避免重复**：生成的分镜可能有重复画面，需要手动检查并要求 AI 修正。
3. **动态场景**：打斗等高动态场景建议使用「最后一帧过渡法」，确保片段间连贯。
4. **适当裁剪**：生成的多段视频可能有部分冗余，可在后期剪辑中删减。
5. **Prompt 结尾**：始终加 `No music. No subtitles.`，让后期更灵活。
6. **角色一致性**：每次生成视频都要引用角色参考表，否则角色外观会产生偏差。
