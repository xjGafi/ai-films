# Seedance 2.0 视频生成参数完整解析

> 基于代码库实现 + Replicate/火山引擎文档 + 社区实践的综合整理

---

## 1. 一致性相关参数

### 1.1 `seed` — 风格锚定

| 属性 | 值 |
|------|-----|
| 类型 | int |
| 默认值 | null（随机） |
| 代码默认值 | 42 |

**作用**：固定随机种子，保证渲染风格、光照倾向、色调一致。

**效果边界**：
- 同一 seed **不保证**角色外观完全一致
- **能保证**的是：渲染风格、光照方向、色彩基调
- 核心价值是减少视觉跳跃感，让多段视频看起来像同一部片子

**使用建议**：同一项目所有片段用相同 seed。

### 1.2 `reference_images` — 视觉锚定（Mode B）

| 属性 | 值 |
|------|-----|
| 类型 | URI[]（图片 URL 或 data URI） |
| 最大数量 | 9 张 |
| 与 image/last_frame_image | **互斥** |

**作用**：角色/风格/场景一致性的核心手段。传入角色参考表、分镜行条、前一段末帧等，模型会尝试保持视觉一致。

**Prompt 中引用方式**：`[Image1]`、`[Image2]`、...、`[Image9]`，按数组顺序对应。

**当前 Pipeline 中的使用优先级**（最多 9 张）：
1. 上一段末帧 `frames/segment-{N-1}-last.png` — 视觉连续性锚点
2. 上一幕最后一行分镜 `storyboard/act-{N-1}-row-3.png` — 环境参考
3. 当前幕 3 行分镜条 `storyboard/act-{N}-row-{1,2,3}.png` — 动作编排参考
4. 角色参考表 `characters/{name}-ref.png` — 角色一致性

**效果**：社区反馈约 70-80% 的角色一致性成功率。配合 prompt 中的详细物理描述可进一步提升。

### 1.3 `image` — 首帧锁定（Mode A）

| 属性 | 值 |
|------|-----|
| 类型 | URI（图片 URL） |
| 与 reference_images | **互斥** |

**作用**：锁定视频第一帧画面，实现帧级精确的段间无缝衔接。典型用法是将上一段视频的最后一帧作为下一段的 `image`。

**适用场景**：同一连续动作（追逐、打斗），需要帧级精确衔接。

### 1.4 `last_frame_image` — 末帧锁定（Mode A）

| 属性 | 值 |
|------|-----|
| 类型 | URI（图片 URL） |
| 前提 | 必须同时设置 `image` |
| 与 reference_images | **互斥** |

**作用**：锁定视频最后一帧，配合 `image` 实现首尾帧双锚定，精确控制视频的起止画面。

## 2. 媒体输入参数

### 2.1 `reference_videos` — 动作/风格迁移

| 属性 | 值 |
|------|-----|
| 类型 | URI[] |
| 最大数量 | 3 个 |
| 总时长限制 | ≤ 15 秒 |
| 当前代码状态 | **未实现** |

**作用**：让生成的视频模仿参考视频的运动节奏、镜头语言或视觉风格。

**Prompt 中引用方式**：`[Video1]`、`[Video2]`、`[Video3]`

**潜在用途**：
- 传入上一段生成的视频片段，让新段模仿运动风格
- 传入真人拍摄的参考视频进行动作迁移

### 2.2 `reference_audios` — 音频驱动

| 属性 | 值 |
|------|-----|
| 类型 | URI[] |
| 最大数量 | 3 个 |
| 总时长限制 | ≤ 15 秒 |
| 当前代码状态 | **未实现** |

**作用**：根据音频内容驱动角色动作，主要用于口型同步（lip sync）。

**Prompt 中引用方式**：`[Audio1]`、`[Audio2]`、`[Audio3]`

**潜在用途**：
- 传入预录制的对白音频，让角色动作与语音同步
- 传入音乐节奏，让动作跟随节拍

## 3. 基础生成参数

### 3.1 `prompt` — 视频描述

| 属性 | 值 |
|------|-----|
| 类型 | string |
| 必填 | 是 |

**说明**：
- 支持 `[ImageN]`/`[VideoN]`/`[AudioN]` 引用语法
- 支持在双引号中写对话触发口型同步：`The character says "Hello"`
- **没有独立的 negative prompt 字段**，必须在 prompt 正文中内联写负面指令
- 高级功能：支持 IPA 音标精确口型控制、FACS 面部编码系统

### 3.2 `duration` — 视频时长

| 属性 | 值 |
|------|-----|
| 类型 | int |
| 默认值 | 5 |
| 可选值 | -1（自动）/ 5 / 10 / 15 |

**说明**：`-1` 让模型根据 prompt 内容自动判断合适时长。当前 Pipeline 固定为 15 秒。

### 3.3 `resolution` — 分辨率

| 属性 | 值 |
|------|-----|
| 类型 | enum |
| 默认值 | "720p" |
| 可选值 | 480p / 720p / 1080p |

**分辨率对照表**：

| 分辨率 | 16:9 | 4:3 | 1:1 | 3:4 | 9:16 |
|--------|------|-----|-----|-----|------|
| 480p | 864×496 | 752×560 | 640×640 | 560×752 | 496×864 |
| 720p | 1280×720 | 1112×834 | 960×960 | 834×1112 | 720×1280 |
| 1080p | 1920×1080 | — | — | — | — |

**注意**：1080p 仅支持 16:9 比例。

### 3.4 `aspect_ratio` — 宽高比

| 属性 | 值 |
|------|-----|
| 类型 | enum |
| 默认值 | "16:9" |
| 可选值 | 16:9 / 4:3 / 1:1 / 3:4 / 9:16 / 21:9 / 9:21 / adaptive |

**说明**：`adaptive` 让模型根据输入图片自动选择最佳比例。

### 3.5 `generate_audio` — 音频生成

| 属性 | 值 |
|------|-----|
| 类型 | bool |
| 默认值 | true |
| 当前代码状态 | **未传参**（隐式使用 API 默认值 true） |

**说明**：设为 `false` 可生成无声视频，适合后期用专业配音替换。

## 4. 明确不支持的参数

以下参数在其他视频模型（如 Kling、Runway）中常见，但 Seedance 2.0 **不提供**：

| 参数 | 说明 |
|------|------|
| **CFG scale** | 无法调节 prompt 遵循度，模型内部处理 |
| **motion strength** | 无法直接控制运动幅度，需通过 prompt 文字描述 |
| **FPS** | 无法控制帧率，模型自动决定 |
| **negative prompt** | 没有独立字段，必须在 prompt 正文中用 `Do not...` 内联 |
| **ControlNet** | 不暴露骨骼/深度/边缘等精细控制，`reference_images` 是最接近的替代 |
| **步数 (steps)** | 无法控制推理步数 |
| **去噪强度 (denoise strength)** | 无法控制 |

## 5. 两种互斥模式对比

| | Mode A（首帧/末帧控制） | Mode B（多参考图） |
|---|---|---|
| **参数** | `image` + `last_frame_image` | `reference_images` |
| **核心能力** | 帧级精确构图控制 | 角色/风格一致性 |
| **构图自由度** | 低（被锁定在起止帧之间） | 高（模型自由发挥） |
| **角色一致性** | 依赖首帧图中的角色 + prompt 文字 | 直接传入角色参考表 |
| **段间衔接** | 最可靠（帧级无缝） | 依赖 CONTINUITY NOTE + seed |
| **适用场景** | 同场景连续动作、精确过渡 | 大多数常规段落 |
| **互斥限制** | 不能同时用 reference_images | 不能同时用 image/last_frame_image |

## 6. 一致性三层防线总结

```
┌─────────────────────────────────────────────────────┐
│  第 1 层：视觉锚定 — reference_images                │
│  角色参考表始终放 reference_images[0]（最高保真度）    │
│  补充分镜行条、前段末帧                               │
├─────────────────────────────────────────────────────┤
│  第 2 层：文本锚定 — prompt 中重复详细物理描述         │
│  每段都完整写角色外观，不用 "same as before"           │
│  用精确色彩词：`charcoal grey wool` 而非 `dark coat`  │
├─────────────────────────────────────────────────────┤
│  第 3 层：风格锚定 — seed 固定                        │
│  同一项目所有片段用相同 seed                           │
│  保证渲染风格、光照、色调一致                          │
└─────────────────────────────────────────────────────┘
```

## 7. 当前 Pipeline 中未利用的能力

| 能力 | 参数 | 潜在价值 |
|------|------|---------|
| 动作迁移 | `reference_videos` | 模仿参考视频运动风格，提升段间动作一致性 |
| 音频驱动 | `reference_audios` | 口型同步，对话场景更自然 |
| 音频控制 | `generate_audio` | 显式关闭音频，后期配音时避免干扰 |
| 首帧/末帧锚定 | `image` + `last_frame_image` | Mode A 已定义接口但未激活，段间衔接最可靠手段 |
| 自适应比例 | `aspect_ratio: "adaptive"` | 根据输入图自动选择最佳比例 |
